# Algora

No-code trading bots for Indian markets (NSE, NFO, MCX): build, backtest, paper trade, then deploy through your own broker.

Static front end. Open `index.html` or serve the folder (GitHub Pages ready, `.nojekyll` included).

See `ACTION_PLAN.md` for the roadmap to a fully working platform.

Live: https://algora007.github.io/algora/

See `CHANGELOG.md` for the 26 Nov 2026 home page review.
